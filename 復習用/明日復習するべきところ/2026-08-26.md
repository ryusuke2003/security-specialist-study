# 2026-08-26に復習するべきところ

採点日: 2026-08-25

#### AEAD — 55点

- [ ] 復習済み

出典: [2026-08-23 / Session 3 / Q7](../../学習記録/暗記語句問題/2026-08-23.md#q7)

**復習の要点**: AEADは電子署名ではない。共通鍵を使い、平文を暗号化して機密性を守るとともに、暗号文・AAD・nonceに対する認証タグで完全性・真正性を確認する。認証タグの検証に失敗したデータは利用せず破棄する。

- 流れ図: [AEADの暗号化と認証タグ検証](../流れ図/AEADの暗号化と認証タグ検証.md)
- 関連する新語: `電子署名` — 秘密鍵で署名を作り、対応する公開鍵で検証して、署名者と改ざんの有無を確認する仕組み。

#### リスク対応 — 75点

- [ ] 復習済み

出典: [2026-08-23 / Session 3 / Q6](../../学習記録/暗記語句問題/2026-08-23.md#q6)

**復習の要点**: リスク対応は、評価したリスクに対して回避・低減・移転・受容の方針を選び実施することである。移転は、保険加入や契約などにより損失負担を他者へ移す対応である。

- 関連する新語: `ISMSとリスクアセスメント` — ISMSは情報セキュリティを継続管理する仕組み、リスクアセスメントはリスクを特定・分析・評価して判断材料にする活動。
