#### RBAC / ABAC — 0点

- [ ] 復習済み

#### ネットワークアクセス制御（NAC） — 20点

- [ ] 復習済み
- 出典: [2026-08-27 / Session 2 / Q12](../../学習記録/暗記語句問題/2026-08-27.md#q12)

- 関連する新語: ゼロトラスト原則

#### 資産管理と攻撃面管理 — 25点

#### DKIM — 75点

- [ ] 復習済み
- 出典: [2026-08-27 / Session 2 / Q17](../../学習記録/暗記語句問題/2026-08-27.md#q17)

#### DNSSEC — 85点

- [ ] 復習済み
- 出典: [2026-08-27 / Session 2 / Q14](../../学習記録/暗記語句問題/2026-08-27.md#q14)

#### ハッシュとMAC — 90点

- [ ] 復習済み
- 出典: [2026-08-27 / Session 2 / Q3](../../学習記録/暗記語句問題/2026-08-27.md#q3)
