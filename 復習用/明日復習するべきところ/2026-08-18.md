**復習の要点**: Active Directory（AD）はWindowsドメイン内の利用者、端末、グループ、権限を集中管理する仕組み。Kerberosは認証後にチケットを使う認証方式で、パスワードをサービスごとに送り続けずに利用者を確認する。

#### CVE / CWE — 45点

- [ ] 復習済み

出典: [2026-08-15 / Session 1 / Q17](../../学習記録/暗記語句問題/2026-08-15.md#q17)

**復習の要点**: CVEは公開された**個別の脆弱性**を識別する番号である。CWEはSQLインジェクションのような脆弱性につながる**ソフトウェア上の弱点の種類**を分類した一覧であり、CVSSはその脆弱性の技術的深刻度を表す。三者は対象が異なる。

- 次に確認する点: CVE＝個別事例、CWE＝弱点分類、CVSS＝深刻度と対比する。

- 関連する新語: `静的解析 / 動的解析` — 静的解析はソースコードを実行せずに弱点候補を調べ、動的解析は実行中の挙動を観測して脆弱性を検出する手法。

#### リスク対応 — 85点

- [ ] 復習済み

出典: [2026-08-15 / Session 1 / Q1](../../学習記録/暗記語句問題/2026-08-15.md#q1)

**復習の要点**: リスク対応は、評価したリスクに対して対策方針を選び実施すること。四つの選択肢は、活動をやめる**回避**、確率や影響を下げる**低減**、保険や契約で損失負担を分ける**移転**、残るリスクを責任者が受け入れる**受容**である。

- 次に確認する点: 四分類を漏れなく挙げ、低減と移転を区別する。

- 関連する新語: `ISMSとリスクアセスメント` — 資産・脅威・脆弱性・影響を評価し、管理策と残余リスクの扱いを決める組織的な枠組み。

出典: [2026-08-15 / Session 1 / Q8](../../学習記録/暗記語句問題/2026-08-15.md#q8)

**復習の要点**: サーバ証明書の署名を中間CAの公開鍵で検証し、中間CAの署名も上位CAの公開鍵で順に検証する。最後は端末の信頼ストアにあるルートCAを起点に信頼を確認するので、上位CAへ問い合わせること自体が本質ではない。

#### CVSSとリスクベース優先順位 — 95点

- [ ] 復習済み

出典: [2026-08-15 / Session 1 / Q3](../../学習記録/暗記語句問題/2026-08-15.md#q3)

**復習の要点**: CVSSは脆弱性そのものの技術的な深刻度を数値化する指標であり、個別組織の資産価値や業務影響は含めない。実際の修正順は、CVSSに加えて資産重要度、悪用の有無・可能性、公開範囲などを考慮して決める。

- 次に確認する点: CVSSは技術的深刻度、資産重要度は組織ごとの優先順位材料と区別する。

- 関連する新語: `KEV / EPSS` — KEVは既知に悪用された脆弱性の情報、EPSSは近い将来に悪用される確率の推定で、修正優先順位の判断材料になる。
