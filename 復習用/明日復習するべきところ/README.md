# 明日復習するべきところ

採点した次の学習日に確認する、短期の復習チェックリストです。学習日の切替はJST午前5時で、00:00〜04:59は前日扱いです。採点した学習日ごとに、次の学習日の日付をファイル名にした `YYYY-MM-DD.md` を作ります。

各ファイルには、その前日に採点した理解・応用問題と暗記語句問題をまとめます。100点以外の回答は、理解できている部分が多くても対象です。恒久ノートである[学んだこと](../学んだこと/README.md)と内容が重複しても構いません。

同じ日に複数のSessionを採点した場合も、翌日分は一つのファイルへ集約します。

各項目は、100点未満なら必ず掲載した上で、点数に応じて優先度を表示します。

採点日に作成・更新した図だけでなく、既存の流れ図が問題内容を直接補う場合も、関連する項目に `流れ図` のリンクを付けます。図がない項目へ、関連の薄い図を付けることはしません。

- **最優先**: 0〜69点
- **確認**: 70〜89点
- **軽い確認**: 90〜99点

問題形式ごとに、**最優先 → 確認 → 軽い確認**の見出しへまとめます。同じ優先度内では、元のSession日付・番号とQ番号の順を保ちます。時間が限られる日は最優先から確認しますが、軽い確認も掲載対象から外しません。
