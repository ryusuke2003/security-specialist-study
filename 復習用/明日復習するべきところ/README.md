# 明日復習するべきところ

採点した次の学習日に確認する、短期の復習チェックリストです。学習日の切替はJST午前5時で、00:00〜04:59は前日扱いです。採点した学習日ごとに、次の学習日の日付をファイル名にした `YYYY-MM-DD.md` を作ります。

各ファイルには、その前日に採点した理解・応用問題と暗記語句問題の100点以外の回答に加え、10分復習で不正解だった問題をまとめます。理解・応用問題と暗記語句問題は、理解できている部分が多くても100点以外なら対象です。恒久ノートである[学んだこと](../学んだこと/README.md)と内容が重複しても構いません。

同じ日に複数のSessionを採点した場合も、翌日分は一つのファイルへ集約します。

各項目は、100点未満なら必ず掲載した上で、問題形式を区別せず点数の低い順に表示します。同点は出典の日付・Session番号・Q番号の順です。

採点日に作成・更新した図だけでなく、既存の流れ図が問題内容を直接補う場合も、関連する項目に `流れ図` のリンクを付けます。図がない項目へ、関連の薄い図を付けることはしません。

各項目は見出し（例: `#### AEAD — 0点`）の直下に、タスクリスト形式の `- [ ] 復習済み` を置きます。出典、**復習の要点**、流れ図、関連する新語も分けて置き、一行が横に長くならないようにします。
