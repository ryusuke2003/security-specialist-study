# 2026-08-24に復習するべきところ

採点日: 2026-08-23

#### DNSSEC — 0点

- [x] 復習済み

出典: [2026-08-22 / Session 2 / Q5](../../学習記録/理解・応用問題/2026-08-22.md#q5)

**復習の要点**: DNSSECは、DNS応答が正当なゾーンの秘密鍵によって署名され、途中で改ざんされていないことを検証する仕組みである。`RRSIG`を`DNSKEY`で検証し、親ゾーンの`DS`（子ゾーンの特定DNSKEYから計算したダイジェスト）と対応するDNSKEYの一致を確認して、ルートから子ゾーンまでの信頼の連鎖をたどる。`DS`と`DNSKEY`は鍵を照合し、`DNSKEY`と`RRSIG`は署名を検証する。検証に失敗した応答は通常`SERVFAIL`として利用・キャッシュしない。DNS通信を暗号化する仕組みではないため、秘匿にはDoTやDoHを別に用いる。鍵更新失敗や署名期限切れは可用性低下を招く。

- 流れ図: [DNSSEC](../流れ図/DNSSEC.md)
- 関連する新語: `RRSIG` — DNSレコード集合に付ける電子署名。

#### EDRテレメトリ — 15点

- [x] 復習済み

出典: [2026-08-21 / Session 1 / Q9](../../学習記録/暗記語句問題/2026-08-21.md#q9)

**復習の要点**: EDRテレメトリは、端末のプロセス、通信、ファイル、ログオンなどの行動を収集し、検知・調査・隔離に使うデータである。単なるログ保存先ではない。

- 関連する新語: `process tree` — 親子プロセスの起動関係を表し、不審な実行連鎖の調査に使う。

#### AEAD — 15点

- [x] 復習済み

出典: [2026-08-22 / Session 2 / Q3](../../学習記録/理解・応用問題/2026-08-22.md#q3)

**復習の要点**: AEADは暗号化と認証タグによる改ざん検知を同時に行う。同一鍵でnonceを再利用せず、タグ検証に失敗したデータは利用せず破棄する。

- 流れ図: [AEADの暗号化と認証タグ検証](../流れ図/AEADの暗号化と認証タグ検証.md)
- 関連する新語: `nonce` — 同一鍵の下で各暗号化処理に重複させない値。

#### DMARC — 30点

- [x] 復習済み

出典: [2026-08-22 / Session 2 / Q4](../../学習記録/理解・応用問題/2026-08-22.md#q4)

**復習の要点**: DMARCはSPFのenvelope-from又はDKIMのd=が表示Fromとalignmentするかを評価する。SPF passだけでは表示Fromの正当性を示せない。

- 流れ図: [DKIMの署名と検証](../流れ図/DKIMの署名と検証.md)
- 関連する新語: `alignment` — SPF又はDKIMで認証したドメインと表示Fromドメインの整合。

#### VPN（IPsec） — 35点

#### IDベースのアクセス制御 — 50点

- [x] 復習済み

出典: [2026-08-21 / Session 1 / Q15](../../学習記録/暗記語句問題/2026-08-21.md#q15)

**復習の要点**: IDベースのアクセス制御は、トークンの有無だけでなく、利用者・端末の属性、端末健全性、要求内容をポリシーで評価して許可を決める。

- 関連する新語: `継続的認可` — セッション開始時だけでなく、端末状態やリスク変化に応じてアクセス可否を再評価すること。

#### ハッシュとMAC — 60点

- [x] 復習済み

出典: [2026-08-21 / Session 1 / Q4](../../学習記録/暗記語句問題/2026-08-21.md#q4)

**復習の要点**: ハッシュは鍵なしで完全性確認に使う要約値、MACは共有秘密鍵を使い完全性と送信者の真正性を確認する認証子である。

- 関連する新語: `HMAC` — ハッシュ関数を共有秘密鍵と組み合わせてMACを計算する方式。

#### ネットワークアクセス制御（NAC） — 60点

- [x] 復習済み

出典: [2026-08-21 / Session 1 / Q17](../../学習記録/暗記語句問題/2026-08-21.md#q17)

**復習の要点**: NACは利用者・端末の認証と端末健全性を基に、ネットワーク接続を許可、制限、隔離する仕組みである。隔離だけでなく接続前後の評価が要点となる。

- 関連する新語: `802.1X` — LANや無線LANで利用者・端末を認証して接続可否を制御する仕組み。

#### OAuth 2.0 / OIDC — 65点

- [x] 復習済み

出典: [2026-08-22 / Session 2 / Q2](../../学習記録/理解・応用問題/2026-08-22.md#q2)

**復習の要点**: OAuth 2.0は認可、OIDCは認証である。認可コードはブラウザへトークンを直接露出させず、PKCEは横取りしたコードの交換を防ぐ。

#### CVE / CWE — 70点

- [x] 復習済み

出典: [2026-08-21 / Session 1 / Q8](../../学習記録/暗記語句問題/2026-08-21.md#q8)

**復習の要点**: CVEは個別の脆弱性情報の識別子、CWEは脆弱性につながるソフトウェア弱点の分類である。攻撃手法の分類と混同しない。

- [x] 復習済み
