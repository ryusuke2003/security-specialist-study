# 認証・認可 / IAM

## 2026-08-21

### SAMLによる認証連携

- SAMLは、IdP（Identity Provider）が認証した利用者の情報を含むSAML Assertionを、SP（Service Provider）へ渡してシングルサインオンを実現するXMLベースの認証連携標準である。
- SPはAssertionをそのまま信用せず、IdPの署名、発行者、宛先、対象者、有効期限などを検証する。IdPが利用者を認証し、SPが検証済みAssertionに基づいて利用を許可する役割分担を押さえる。

## 2026-08-23

### OAuth 2.0 / OIDCとPKCE

- OAuth 2.0はAPIへのアクセス権限を委譲する**認可**の枠組みであり、OIDCはその上にIDトークンを加えて利用者を確認する**認証**の仕様である。
- 認可コードフローではブラウザへアクセストークンを直接返さず、クライアントがトークンエンドポイントで認可コードを交換する。公開クライアントは秘密を安全に保持できないため、PKCEで`code_challenge`と`code_verifier`を照合し、横取りした認可コードの交換を防ぐ。
