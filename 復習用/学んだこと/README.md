# 学んだこと

採点や学習中に得た、後で読み返す価値のある文章メモを分野別に整理する場所です。新しいメモは、記入した日付を `## YYYY-MM-DD`（JST）で示し、同じファイルの同日分は同じ見出しに続けて追記します。処理手順を図で確認したい内容は、[流れ図](../流れ図/)を参照します。

- [暗号・PKI](暗号・PKI.md): 暗号化、署名、証明書、TLS、HTTP/HTTPS
- [メールセキュリティ](メールセキュリティ.md): SMTPとTLS、メール送受信の役割
- [Webセキュリティ](Webセキュリティ.md): CSRF、SameSite、SQLインジェクション
- [認証・認可 / IAM](認証・認可_IAM.md): SAMLによる認証連携
- [リスク・ガバナンス](リスク・ガバナンス.md): リスク対応と残余リスク
- [DNS](DNS.md): DNSSECとRRSIG検証
- [OSセキュリティ](OSセキュリティ.md): Active DirectoryとKerberos
- [フォレンジック](フォレンジック.md): 揮発性データの保全
- [ログ分析・監視](ログ分析・監視.md): EDRテレメトリと検知ユースケース
- [サプライチェーン](サプライチェーン.md): 依存関係混同
- [脆弱性管理](脆弱性管理.md): CVE/CWE、攻撃面、例外管理
- [クラウドセキュリティ](クラウドセキュリティ.md): IaaSの責任共有モデル、IAM、OSパッチ管理
- [ネットワークセキュリティ](ネットワークセキュリティ.md): IPsecトンネルモード、IKE、ESP
- [ゼロトラスト](ゼロトラスト.md): 継続的検証、最小権限、分離

新しい文章メモは、最も近い分野のファイルへ追記します。既存の説明と重複する場合は追加しません。分野の境界が分かりにくくなった場合は、ファイルの追加・統合・内容の再配置と、この一覧の更新を行います。
