## 各Markdownの役割

- `やるべきこと.md`
  - 前回の学習記録、未復習一覧、未解答一覧を確認し、10分復習または次の問題へ進むためのリンク付きチェックリストです。

- `学習記録/理解・応用問題/YYYY-MM-DD.md`
  - 理解・応用問題、回答、問題別採点、短い模範説明を保存します。

- `学習記録/暗記語句問題/YYYY-MM-DD.md`
  - 暗記語句問題と回答・採点を保存します。
  - 同じ日のSession番号は、両ディレクトリを通した連番です。

- `学習記録/10分復習/YYYY-MM-DD.md`
  - 期限超過・当日復習・低得点を優先した3択の短時間復習を保存します。選択肢のチェックボックスを一つだけ選んで回答します。
  - 正答は理解度やカバレッジを更新せず、不正解は次回候補として扱い、次の学習日用チェックリストにも記載します。

- `進捗/語句別理解度.md`
  - 概念単位の総合理解度、暗記語句／通常説明別の理解度、平均点、直近点を保存します。
  - 科目区分、出題回数、反映済みSession台帳、暗記／通常説明それぞれの最終学習日・次回復習日、関連概念、弱点メモも管理します。

- `進捗/分野別理解度.md`
  - 語句スコアと直近の解答実績から、分野単位の理解度を推定します。
  - 点数・Levelに加え、暗記だけか応用まで確認済みか、高難度で安定した証拠があるかを表示します。暗記・応用・高難度成功の問題数、重要度4〜5で未評価の語句数も確認できます。

- `進捗/モチベ.md`
  - カタログ語句を未評価・暗記のみ・応用のみ・両方確認に分けたMermaid円グラフと、分野別の同じ内訳を表示します。採点時に自動更新します。

- `進捗/学習履歴.md`
  - 各Sessionの平均点、科目B比率、弱点、次の復習候補を時系列で保存します。

- `学習記録/未解答一覧.md`
  - 回答欄が空の問題を、モード、日付、Session番号、問題番号の範囲だけで一覧表示します。
  - 各行全体のリンクから元のSessionファイルを開けます。`わかりません` は回答済みとして扱います。
  - 問題作成・採点の後に補助スクリプトで更新します。

- `学習記録/行ったこと.md`
  - 採点したSessionを、採点日（JST午前5時切替）と問題形式ごとのリンク一覧として残します。
  - Sessionに記録した`Graded`日を使うため、Gitのコミット日時や未コミット状態には依存しません。採点時に対象日を追記し、過去の日付は残します。

- `過去問/`
  - IPAの問題冊子、解答例、採点講評をローカルだけに保存します。`.gitignore`によりPDFはリモートへ送られません。
  - 利用者がカタログ拡張または過去問を踏まえた用語追加を明示したときだけ、このディレクトリのPDFを分析します。
  - 空または未作成なら、公式サイトの公開資料を参照します。

- `参照資料/過去問分析索引.md`
  - PDF分析から得た頻出テーマ、追加候補語句、根拠年度を保存します。
  - 日々の出題ではPDFも索引も読まず、カタログを更新するレビュー時にだけ索引を参照します。

- `復習用/学んだこと/*.md`
  - 学習中に整理した文章や表を分野ごとに保存します。`README.md`を入口にします。
  - 恒久メモに値する内容は、JST午前5時を境にする学習日を `## YYYY-MM-DD` で示して最も近い分野のファイルへ追記します。
  - 同じファイルの同日分では日付見出しを繰り返さず、必要に応じて分野ファイルを追加・統合・再配置します。

- `復習用/明日復習するべきところ/YYYY-MM-DD.md`
  - その前の学習日に採点した暗記語句問題・理解問題のうち100点以外の回答と、10分復習の不正解を次の学習日用に一つへまとめます。学習日はJST午前5時で切り替わります。
  - 採点日に作成または内容を補った対応する流れ図がある場合は、問題項目からその図へリンクします。
  - 各項目には、元の問題を開かなくても復習できる短い解説と、関連する新語一つを付けます。
  - 出典は元のSessionの該当問題見出しへ直接移動できるリンクにします。
  - 問題形式を分けず、点数の低い順にまとめます。同点は出典の日付・Session番号・Q番号順です。
  - `学んだこと/`との重複は許可し、同じ採点日に複数Sessionを処理しても同じ日付ファイルへ追記します。

- `復習用/未復習一覧.md`
  - 日付別の復習ノートで `- [ ] 復習済み` のままの項目だけを、点数の低い順に一覧化します。
  - 内容の正本ではなくリンクだけの自動生成ビューです。問題作成・採点後、または手動チェック後に補助コマンドで更新します。

- `復習用/流れ図/*.md`
  - 複数の主体・処理順・分岐を図で確認した方がよいテーマをMermaid図として保存します。
  - 採点時に新しい図が必要な場合もこのディレクトリへ作成し、同じ学習目的の図は重複作成しません。

- `参照資料/出題分類と概念カタログ.md`
  - 出題分野、正式な語句名、科目B重要度、前提・関連関係を定義します。

- `参照資料/採点・理解度・復習ルール.md`
  - 100点評価、理解度更新、難易度、忘却度、復習間隔の共通規則です。

- `参照資料/セッション形式.md`
  - Sessionの保存先、必須メタデータ、共通検証を定義します。

- `参照資料/通常・暗記語句Session形式.md` と `参照資料/10分復習Session形式.md`
  - モードごとの問題・回答形式を定義します。採点済みSessionの形式は採点ワークフローを正本とします。

## データ管理方針

学習の正本は `学習記録/` と `進捗/` のMarkdownです。

補助スクリプトは候補の順位付けと、採点済みSessionから進捗への冪等な反映を行います。実装は`scripts/trainer/`で責務別に分割し、`study_helper.py`が従来のコマンドとPython APIを再公開します。学習履歴をJSONなどの別状態へ隠しません。

問題作成または採点の共通開始処理は`skills/security-specialist-trainer/references/共通開始処理.md`を正本とします。新しいSessionは`validate-session`で回答開始前に形式を検証します。採点後は`record`が未解答一覧を、翌日復習ノート作成後の`unreviewed`が未復習一覧を更新します。

作業中に得られた、再利用可能な正確性・安全性・分かりやすさに関する知見は、必要に応じてSkill、手順書、参照資料へ反映します。

一時的な事情や個別案件だけに固有の内容は恒久ルールにしません。

変更によって不要になった可能性のあるファイル、生成物、重複ノートは自動削除しません。

削除候補と理由・影響を示したうえで、利用者に削除の判断を依頼します。
