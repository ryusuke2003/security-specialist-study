## 各Markdownの役割

- `sessions/理解・応用問題/YYYY-MM-DD.md`: 理解・応用問題、回答、問題別採点、短い模範説明を保存します。
- `sessions/暗記語句問題/YYYY-MM-DD.md`: 暗記語句問題と回答・採点を保存します。同じ日のSession番号は両ディレクトリを通した連番にします。
- `progress/terms.md`: 概念単位の総合理解度、暗記語句／通常説明別の理解度、平均点、直近点、科目区分、出題回数、反映済みSession台帳、最終学習日、次回復習日、関連概念、弱点メモを保存します。
- `progress/domains.md`: 分野単位の理解度を、語句スコアと直近の解答実績から推定します。
- `progress/history.md`: 各Sessionの平均点、科目B比率、弱点、次の復習候補を時系列で保存します。
- `過去問/`: IPAの問題冊子、解答例、採点講評を保存します。2010〜2025年度の初回アーカイブは出典表記付きでGit管理し、`.gitignore`により以後追加する未追跡ファイルはリモートへ送られません。カタログ拡張時は、このディレクトリにある資料をオンライン資料より先に参照します。空または未作成なら、公式サイトの公開資料を参照します。
- `復習用/学んだこと.md`: 学習中に整理した文章や表を保存します。
- `復習用/流れ図/*.md`: 複数の主体・処理順・分岐を図で確認した方がよいテーマをMermaid図として保存します。採点時に新しい図が必要な場合もこのディレクトリへ作成し、既存の図と同じ学習目的の図は重複作成しません。
- `references/taxonomy.md`: 出題分野、正式な語句名、科目B重要度、前提・関連関係を定義します。
- `references/scoring-rules.md`: 100点評価、理解度更新、難易度、忘却度、復習間隔の共通規則です。
- `references/session-format.md`: Sessionの保存先、必須メタデータ、問題・回答・採点のMarkdown形式を定義します。

## データ管理方針

学習の正本は `sessions/` と `progress/` のMarkdownです。補助スクリプトは候補の順位付けと、採点済みSessionからprogressへの冪等な反映を行います。学習履歴をJSONなどの別状態へ隠しません。

作業中に得られた、再利用可能な正確性・安全性・分かりやすさに関する知見は、必要に応じてSkill、手順書、参照資料へ反映します。一時的な事情や個別案件だけに固有の内容は恒久ルールにしません。

変更によって不要になった可能性のあるファイル、生成物、重複ノートは自動削除しません。削除候補と理由・影響を示したうえで、利用者に削除の判断を依頼します。
