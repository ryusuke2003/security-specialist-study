## 各Markdownの役割

- `やるべきこと.md`
  - 前回の学習記録、未復習一覧、未解答一覧を確認し、10分復習または次の問題へ進むためのリンク付きチェックリストです。

- `学習記録/理解・応用問題/YYYY-MM-DD.md`
  - 理解・応用問題、回答、問題別採点、短い模範説明を保存します。

- `学習記録/暗記語句問題/YYYY-MM-DD.md`
  - 暗記語句問題と回答・採点を保存します。
  - 同じ日のSession番号は、各問題形式を通した連番です。

- `学習記録/10分復習/YYYY-MM-DD.md`
  - 期限超過・当日復習・低得点を優先したA/B/C三択と`D. わかりません`の短時間復習を保存します。チェックボックスを一つだけ選んで回答します。
  - 正答は理解度やカバレッジを更新せず、不正解またはDは次回候補として扱い、次の学習日用チェックリストにも記載します。

- `進捗/語句別理解度.md`
  - 概念単位の総合理解度、暗記語句／通常説明別の理解度、平均点、直近点を保存します。
  - 科目区分、出題回数、反映済みSession台帳、暗記／通常説明それぞれの最終学習日・次回復習日、関連概念、弱点メモも管理します。

- `進捗/分野別理解度.md`
  - 語句スコアと直近の解答実績から、分野単位の理解度を推定します。
  - 点数・Levelに加え、暗記だけか応用まで確認済みか、高難度で安定した証拠があるかを表示します。暗記・応用・高難度成功の問題数、重要度4〜5で未評価の語句数も確認できます。

- `進捗/モチベ.md`
  - カタログ語句を未評価・暗記のみ・応用のみ・両方確認に分けたMermaid円グラフと、分野別の同じ内訳を表示します。採点時に自動更新します。

- `進捗/学習履歴.md`
  - 各Sessionの平均点、科目B比率、弱点、次の復習候補を時系列で保存します。

- `学習記録/未解答一覧.md`
  - 回答欄が空の問題を、モード、日付、Session番号、問題番号の範囲だけで一覧表示します。
  - 各行全体のリンクから元のSessionファイルを開けます。`わかりません`は回答済みとして扱います。
  - 問題作成・採点の後に補助スクリプトで更新します。

- `学習記録/行ったこと.md`
  - 採点したSessionを、採点日（JST午前5時切替）と問題形式ごとのリンク一覧として残します。
  - Sessionに記録した`Graded`日を使うため、Gitのコミット日時や未コミット状態には依存しません。

- `過去問/`
  - IPAの問題冊子、解答例、採点講評をローカルだけに保存します。`.gitignore`によりPDFはリモートへ送られません。
  - 利用者がカタログ拡張または過去問を踏まえた用語追加を明示したときだけ、このディレクトリのPDFを分析します。
  - 空または未作成なら、公式サイトの公開資料を参照します。

- `参照資料/過去問分析索引.md`
  - PDF分析から得た頻出テーマ、追加候補語句、根拠年度を保存します。
  - 日々の出題ではPDFも索引も読まず、カタログを更新するレビュー時にだけ索引を参照します。

- `参照資料/出題分類と概念カタログ.md`
  - 出題分野、正式な語句名、科目B重要度、前提・関連関係を定義します。

- `参照資料/採点・理解度・復習ルール.md`
  - 採点の意味、Primary TermsとRelated Terms、RecallとExplanation、quick-reviewの位置付けなど、人が理解するための共通概念を説明します。
  - 数値計算式や境界値は持たず、通常の採点ワークフローからも必須読込しません。

- `参照資料/進捗計算仕様.md`
  - Score、復習日、Suggested Level、候補優先度、分野理解度などの計算を変更・デバッグ・詳細説明するときの入口です。
  - 具体的な数値定数の正本は`skills/security-specialist-trainer/scripts/trainer/`配下のPython実装とテストであり、この文書は対応する関数を案内します。
  - 通常の作問・採点では読みません。

- `参照資料/セッション形式.md`
  - Sessionの保存先、必須メタデータ、共通検証を定義します。

- `参照資料/通常・暗記語句Session形式.md` と `参照資料/10分復習Session形式.md`
  - モードごとの問題・回答形式を定義します。採点済みSessionの形式は、通常・暗記語句用と10分復習用の各採点ワークフローを正本とします。

- `復習用/学んだこと/*.md`
  - 学習中に整理した文章や表を分野ごとに保存します。`README.md`を入口にします。
  - 恒久メモに値する内容は、JST午前5時を境にする学習日を`## YYYY-MM-DD`で示して最も近い分野のファイルへ追記します。
  - 同じファイルの同日分では日付見出しを繰り返さず、必要に応じて分野ファイルを追加・統合・再配置します。

- `復習用/明日復習するべきところ/YYYY-MM-DD.md`
  - 採点した暗記語句問題・理解問題のうち100点以外の回答と、10分復習の不正解・`D. わかりません`を次の学習日用に一つへまとめます。Session作成日ではなく実際の採点日を基準にします。
  - 必要な場合は対応する流れ図へリンクし、元の問題を開かなくても復習できる短い解説と関連する新語を付けます。
  - 問題形式を分けず点数の低い順にまとめ、同点は出典の日付・Session番号・Q番号順にします。

- `復習用/未復習一覧.md`
  - 日付別の復習ノートで未チェックの項目だけを一覧化する自動生成ビューです。新規項目の正規形は`- [ ] 復習済み`です。

- `復習用/流れ図/*.md`
  - 複数の主体・処理順・分岐を、先頭のSVG概要図と折り畳みの詳細Mermaid図で確認します。主体、送信者・受信者・送信物、受信後の検証、処理後の保持物を具体的に示します。

## データ管理方針

学習の正本は`学習記録/`と`進捗/`のMarkdownです。補助スクリプトは候補の順位付けと、採点済みSessionから進捗への冪等な反映を行います。学習履歴をJSONなどの別状態へ隠しません。

Skillはルーティングを担当し、作問・採点時には必要な手順書だけを読みます。通常の採点では、回答の意味評価に必要な`採点ワークフロー.md`だけを中心に使い、Score更新式や復習間隔などの計算仕様を毎回コンテキストへ入れません。

数値計算の正本は、`common.py`、`planner.py`、`progress.py`などのPython実装と回帰テストです。`参照資料/進捗計算仕様.md`は、計算を変更・デバッグ・詳細説明するときに、どの実装を見るべきかを示す案内です。Level境界、混合率、復習間隔、候補優先度の係数などを複数のMarkdownへ重複記載しません。

問題作成または採点の共通開始処理は`skills/security-specialist-trainer/references/共通開始処理.md`を正本とします。通常・暗記語句の採点は`採点ワークフロー.md`、10分復習は`10分復習採点ワークフロー.md`を使います。新しいSessionは`validate-session`で回答開始前に検証し、採点後は`record`へ派生進捗の計算とSession確定を任せます。

作業中に得られた再利用可能な正確性・安全性・分かりやすさに関する知見は、必要に応じてSkill、手順書、参照資料へ反映します。一時的な事情や個別案件だけに固有の内容は恒久ルールにしません。

変更によって不要になった可能性のあるファイル、生成物、重複ノートは自動削除しません。削除候補と理由・影響を示したうえで、利用者に削除の判断を依頼します。

CLIが形式不良や進捗の不整合を検出した場合は、表示された原因を修正して再実行し、AI側で黙って補正して続行しません。実装内部のrollback、旧形式互換、パーサの細かな異常系はコードとテストで保証し、通常のSkill手順へ重複記載しません。
