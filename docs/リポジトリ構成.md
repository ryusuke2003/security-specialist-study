## 各Markdownの役割

- `学習記録/理解・応用問題/YYYY-MM-DD.md`
  - 理解・応用問題、回答、問題別採点、短い模範説明を保存します。

- `学習記録/暗記語句問題/YYYY-MM-DD.md`
  - 暗記語句問題と回答・採点を保存します。
  - 同じ日のSession番号は、両ディレクトリを通した連番です。

- `学習記録/10分復習/YYYY-MM-DD.md`
  - 期限超過・当日復習・低得点を優先した3択の短時間復習を保存します。
  - 正答は理解度やカバレッジを更新せず、不正解だけを次回候補として扱います。

- `進捗/語句別理解度.md`
  - 概念単位の総合理解度、暗記語句／通常説明別の理解度、平均点、直近点を保存します。
  - 科目区分、出題回数、反映済みSession台帳、暗記／通常説明それぞれの最終学習日・次回復習日、関連概念、弱点メモも管理します。

- `進捗/分野別理解度.md`
  - 語句スコアと直近の解答実績から、分野単位の理解度を推定します。
  - 点数・Levelに加え、暗記だけか応用まで確認済みか、高難度で安定した証拠があるかを表示します。暗記・応用・高難度成功の問題数、重要度4〜5で未評価の語句数も確認できます。

- `進捗/学習履歴.md`
  - 各Sessionの平均点、科目B比率、弱点、次の復習候補を時系列で保存します。

- `学習記録/未解答一覧.md`
  - 回答欄が空の問題を、モード、日付、Session番号、問題番号の範囲だけで一覧表示します。
  - 各行全体のリンクから元のSessionファイルを開けます。`わかりません` は回答済みとして扱います。
  - 問題作成・採点の後に補助スクリプトで更新します。

- `過去問/`
  - IPAの問題冊子、解答例、採点講評をローカルだけに保存します。`.gitignore`によりPDFはリモートへ送られません。
  - 151語または約250語の暗記一周時、又は利用者が明示したときだけ、このディレクトリのPDFを分析します。
  - 空または未作成なら、公式サイトの公開資料を参照します。

- `参照資料/過去問分析索引.md`
  - PDF分析から得た頻出テーマ、追加候補語句、根拠年度を保存します。
  - 日々の出題ではPDFも索引も読まず、カタログを更新するレビュー時にだけ索引を参照します。

- `復習用/学んだこと/*.md`
  - 学習中に整理した文章や表を分野ごとに保存します。`README.md`を入口にします。
  - 恒久メモに値する内容は、記入日を `## YYYY-MM-DD`（JST）で示して最も近い分野のファイルへ追記します。
  - 同じファイルの同日分では日付見出しを繰り返さず、必要に応じて分野ファイルを追加・統合・再配置します。

- `復習用/明日復習するべきところ/YYYY-MM-DD.md`
  - その前日に採点した暗記語句問題・理解問題のうち、100点以外の回答を翌日用に一つへまとめます。
  - 採点日に作成または内容を補った対応する流れ図がある場合は、問題項目からその図へリンクします。
  - 各項目には、元の問題を開かなくても復習できる短い解説と、関連する新語一つを付けます。
  - 問題形式ごとに、0〜69点の「最優先」、70〜89点の「確認」、90〜99点の「軽い確認」へまとめます。
  - `学んだこと/`との重複は許可し、同じ採点日に複数Sessionを処理しても同じ日付ファイルへ追記します。

- `復習用/流れ図/*.md`
  - 複数の主体・処理順・分岐を図で確認した方がよいテーマをMermaid図として保存します。
  - 採点時に新しい図が必要な場合もこのディレクトリへ作成し、同じ学習目的の図は重複作成しません。

- `参照資料/出題分類と概念カタログ.md`
  - 出題分野、正式な語句名、科目B重要度、前提・関連関係を定義します。

- `参照資料/採点・理解度・復習ルール.md`
  - 100点評価、理解度更新、難易度、忘却度、復習間隔の共通規則です。

- `参照資料/セッション形式.md`
  - Sessionの保存先、必須メタデータ、問題・回答・採点のMarkdown形式を定義します。

## データ管理方針

学習の正本は `学習記録/` と `進捗/` のMarkdownです。

補助スクリプトは候補の順位付けと、採点済みSessionから進捗への冪等な反映を行います。学習履歴をJSONなどの別状態へ隠しません。

作業中に得られた、再利用可能な正確性・安全性・分かりやすさに関する知見は、必要に応じてSkill、手順書、参照資料へ反映します。

一時的な事情や個別案件だけに固有の内容は恒久ルールにしません。

変更によって不要になった可能性のあるファイル、生成物、重複ノートは自動削除しません。

削除候補と理由・影響を示したうえで、利用者に削除の判断を依頼します。
