# 流れ図の読み方とテーマ一覧

`復習用/流れ図/`の図は、**誰が、誰に、何を送り、誰が何を検証するか**を追うための復習資料です。各ファイルの「前提と登場人物」から読み、必要な段階の図を見て、最後に「処理後に残るもの」を確認します。構成例や省略範囲はファイルごとに異なります。

## 図の読み方

`sequenceDiagram`は上から下へ時間が進みます。矢印の始点が操作・送信する主体、終点が相手です。同じ主体へ戻る矢印は、その主体の内部で行う検証・計算・保存です。線の実線・破線だけから暗号化の有無や通信路を判断しないでください。同じ端末内の役割を別列で描くこともあります。

矢印上の番号は各図内の順番です。別図で1に戻っても別の認証を始めたという意味ではなく、見出しと前提に従って段階をつなぎます。`flowchart`では通信順だけでなく、判断や計算の依存関係を示す場合があります。図の前にある説明を確認してください。

**失敗時にどこで止まるか**も大切です。例えば、CORSの送信前の拒否と送信後の読取り拒否、EDRへの対応指示と実行完了、Kerberosによる認証とファイルアクセスの認可は別です。各テーマの注意点と参照資料も合わせて確認してください。

## 編集・検証する場合

[流れ図作成ルール](../skills/security-specialist-trainer/references/流れ図作成ルール.md)を使います。構造テストは明示的な主体・主語・番号・リンク・必須節の欠落を検出しますが、Mermaidの構文やプロトコルの正しさは保証しません。変更した全図のレンダリングと、仕様・公式資料に照らした内容確認を別に行います。

ガイドは索引であり、各テーマの内容の正本は従来どおり`復習用/流れ図/`内の各ファイルです。元ファイル名を維持することで、既存の復習ノートからのリンクを保ちます。
