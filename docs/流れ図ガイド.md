# 流れ図の読み方とテーマ一覧

`復習用/流れ図/`の図は、**誰が、誰に、何を送り、誰が何を検証するか**を追うための復習資料です。各ファイルの「前提と登場人物」から読み、必要な段階の図を見て、最後に「処理後に残るもの」を確認します。構成例や省略範囲はファイルごとに異なります。

## 図の読み方

各資料の先頭に**SVGの概要図**があります。左の番号を上から追い、色付きの主体名と、その下の処理内容を読んでください。色だけに意味を持たせず、主体名と線でも区別しています。画像を開けば拡大できます。

**横矢印は情報の受渡し**、両向き矢印は要求と応答の交換です。同じ端末内の役割間でも使うため、すべてがネットワーク通信という意味ではありません。「内部処理」「確認・判断」には通信矢印を付けません。「＋」は複数担当の並行作業です。左の縦線は読み順だけを示します。

番号は概要図全体の読み順を示します。比較する方式や条件別の経路を別の段階にしている資料もあるので、全段階を連続実行すると解釈しないでください。概要図は重要な操作に絞っています。省略した前提や失敗時の停止条件は「前提と登場人物」「注意点」と合わせて読みます。

「図の内容を文字で読む」を開くと、画像と同じ内容の表を読めます。「詳しい手順・分岐を開く（Mermaid）」には、登録・認証・通常通信などの詳細図を残しています。詳細のシーケンス図は上から下へ進み、自己矢印は同じ主体の内部処理です。フローチャートは図の前の説明に従い、判断や計算依存も表します。

**失敗時にどこで止まるか**も確認してください。CORSの送信前拒否と受信後の読取り拒否、EDRの対応指示と実行完了、Kerberosの認証とサービス側の認可は別です。

## 編集・検証する場合

[流れ図作成ルール](../skills/security-specialist-trainer/references/流れ図作成ルール.md)に従います。概要図は各Markdownの`overview:start`〜`overview:end`内の表を編集し、標準ライブラリだけのコマンドで再生成します。

```bash
python3 skills/security-specialist-trainer/scripts/render_overviews.py
python3 skills/security-specialist-trainer/scripts/render_overviews.py --check
```

生成されたSVGは資料の一部としてコミットします。別のJSON原稿や画像だけの手修正は不要です。概要図と詳細図の内容をそろえ、変更した画像を実際に表示して文字切れ・重なりも確認してください。構造・再生成テストだけで技術内容や表示を保証するものではありません。詳細Mermaidを変更した場合はその描画も確認します。

このガイドは索引です。内容の正本と既存リンク先は、引き続き`復習用/流れ図/`内の各Markdownです。作業の監査報告書は追加せず、変更理由と検証結果はPR本文へ記します。
