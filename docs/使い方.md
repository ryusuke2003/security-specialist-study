# 使い方

## Skillの起動条件

`security-specialist-trainer` は、次のような意図で使用します。

- 「問題作って」「今日の問題」「セキスペ勉強しよう」「5問出して」
- 「暗記単語問題作って」「暗記語句問題作って」「単語問題10問」「暗記問題20問作って」
- 「軽く復習」「Web系多め」「科目Bっぽく」「苦手中心」「新しい単語多め」
- 「採点して」「答え合わせして」「レビューして」
- 「今日の結果どう？」「理解度見せて」「今の弱点は？」

このリポジトリを作業場所として開けば、`AGENTS.md` がこれらの自然言語リクエストをローカルSkillへ誘導します。Skillを明示する場合は `$security-specialist-trainer` と指定します。

## 2種類の問題

### 理解・応用問題

原理、成立条件、対策とその理由、比較、ログや設定の読み取り、シナリオへの適用を説明します。

- 通常は6問です（弱点2問、復習1問、新規2問、発展1問）。
- 7問以上を指定した場合、6問を超える分はすべて新規問題にします。
- 初回の診断では、指定がなければ8分野から1問ずつ出題します。

作成先は `学習記録/理解・応用問題/YYYY-MM-DD.md` です。

### 暗記語句問題

提示された語句の核を一文で言えるかを確かめる想起練習です。

たとえば責任共有モデルなら、「クラウドの提供側と利用者側で責任を分担すること。」で十分です。目的・特徴・仕組みの詳説は求めません。

- 指定がなければ10問、指定時は1〜30問です。
- Aは `floor(問題数 × 40%)`、Bは残りです。10問ならA4問／B6問になります。
- 両Trackとも、Level 1の短い「○○とは何ですか？」形式を維持します。

IPAの最新シラバス・過去問PDFは、「カタログを拡張して」「過去問を踏まえて用語を追加して」などと明示した場合だけ分析します。現行カタログの全語に回答しても、自動では分析しません。

1. [過去問分析索引](../参照資料/過去問分析索引.md)へ、頻出テーマ・候補語句・根拠年度を記録します。
2. 根拠がある未登録の重要語だけを追加します。
3. 既存語句の削除・改名・重複追加はしません。

日々の出題でPDFや索引を読むことはありません。ただし、「過去問を参照して」と明示すればPDFを確認します。通常問題だけの回答はこの周回に含めません。

各問題の `Primary Terms` は1語句に限定します。taxonomy上の複合名称は1語句として扱います。

作成先は `学習記録/暗記語句問題/YYYY-MM-DD.md` です。

### 今日の10分復習

「今日の10分復習」と依頼すると、既定8問のA/B/Cによる3択を作成します。選択肢のチェックボックスを一つだけ選んで回答します。未チェックまたは複数チェックは未回答です。配分は期限超過4問、今日が復習日の語句2問、低得点語句2問を優先し、候補不足時だけ優先度順に補います。

正解は偶然でも選べるため、正答でRecall ScoreやExplanation Scoreを上げません。不正解は短い解説とともに、次の学習日用の `復習用/明日復習するべきところ/YYYY-MM-DD.md` に残します。通常の記述式問題を置き換えるものではなく、学習を始める入口です。

このリポジトリでは、問題作成または採点を始めるときだけ、その日の10分復習がなければ先に1Sessionを自動作成します。当日分があれば後続の学習操作では重複作成しません。挨拶や資料確認では作成しません。「今日の10分復習」または「復習問題作って」と明示した場合は、当日分があっても依頼したSessionを作成します。明示的に学習記録を変更しないよう求められた場合だけ作成しません。

学習日の切替はJST午前5時です。00:00〜04:59の「今日」は前日扱いとなり、10分復習の作成先・重複判定・採点後の翌日復習も同じ基準で日付を決めます。

## 学習の流れ

1. チャットで「問題作って」または「暗記語句問題作って」と依頼する。

2. 理解・応用問題・暗記語句問題は各 `### 回答` の下へMarkdownで回答を書く。10分復習は選択肢のチェックボックスを一つ選ぶ。

3. チャットで「採点して」と依頼する。
   - 全回答済みで未採点のSessionは、古い順にすべて処理されます。
   - `awaiting_answers`のままでも、回答内容がそろっていれば対象です。

4. 問題別の採点と3つのprogressファイルが更新される。
   - 空欄を含むSessionは飛ばされ、未回答の問題番号だけが通知されます。
   - 同じ採点日に完了したSessionは、`学習記録/行ったこと.md`へ問題形式別のリンク一覧として追記されます。

5. 理解・応用問題と暗記語句問題の100点以外の回答、および10分復習の不正解は、次の学習日用に `復習用/明日復習するべきところ/YYYY-MM-DD.md` へ集約される。
   - 問題形式を分けず、点数の低い順にまとめます。同点は出典の日付・Session番号・Q番号順です。
   - 未チェック項目だけを見たいときは、`復習用/未復習一覧.md` を開きます。手動でチェックを変えた後は「未復習一覧を更新して」と依頼します。
   - 各項目は見出しの直下にタスクリスト形式のチェック欄を置き、出典・復習の要点・流れ図・関連する新語を分けて表示します。
   - 必要に応じて、文章の復習メモは `復習用/学んだこと/<分野>.md` に、Mermaid図解は `復習用/流れ図/` に追加されます。
   - 採点日に新しく作成または内容を補った図がその問題に対応する場合は、翌日用チェックリストの項目から図へ移動できます。

6. 翌日以降、再び問題を作成する。
   - 過去の結果と復習期限が、次の選択へ反映されます。
   - Session Summaryの「次回復習」は固定の予定日ではありません。学習を再開したときに優先して扱う目安です。
   - 未回答問題に割り当て済みの語句は通常の出題から除外されます。未回答問題を復習したいと明示した場合だけ、再出題します。

分量や傾向は自然文で変更できます。

例: 「今日は3問」「Web系を多めに」「新しい概念多め」「科目Bのログ分析っぽく」「暗記語句問題を20問」

指定できる問題数は、どちらのモードも1〜30問です。

## 回答と採点結果

問題文やメタデータは変更せず、理解・応用問題と暗記語句問題は各 `### 回答` 見出しの下へ回答を書きます。10分復習は選択肢のチェックボックスだけで回答するため、`### 回答`欄を置きません。

理解・応用問題、暗記語句問題のいずれでも、思い出せない場合は空欄ではなく `わかりません` と記入します。この記入は回答済みとして `0 / 100` で採点され、復習対象として履歴に反映されます。

採点対象はStatusではなく、Session本文の各回答欄に実際に記入されている内容で決まります。Gitの未コミット差分・コミット履歴・作業ツリーの状態は見ません。そのため、回答をコミット済みでも全回答済みで進捗更新まで完了していないSessionは、古い順に処理します。

採点後は、次の内容が同じSessionへ追記されます。

- 点数
- 良かった点
- 足りない点
- 短い模範説明
- 次回確認する観点
- 採点日（`Graded`）

`学習記録/行ったこと.md`は、この採点日を基に採点済みSessionを日付別に残します。Gitのコミット日時では判定しないため、回答や採点をまとめてコミットしても一覧の内容は変わりません。

詳しいSession形式は [セッション形式](../参照資料/セッション形式.md)、評価基準は [採点・理解度・復習ルール](../参照資料/採点・理解度・復習ルール.md)を参照してください。
