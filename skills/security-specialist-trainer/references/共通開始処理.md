# 学習操作の共通開始処理

問題作成または採点を始める前に、この処理を一度だけ行う。進捗報告、挨拶、資料確認など、問題作成・採点を伴わない依頼では行わない。

1. `python3 skills/security-specialist-trainer/scripts/study_helper.py study-date --root .` を実行し、JST午前5時切替の学習日を取得する。00:00〜04:59は前日として扱い、既存ファイル名から推測しない。
2. 利用者が「今日の10分復習」「復習問題作って」と明示した場合は、既存Sessionの有無にかかわらず依頼されたquick-review Sessionを作成する。そのSessionが当日の共通確認も満たす。
3. それ以外では、取得した学習日を指定して `quick-review-status` を実行する。非取消のquick-review Sessionがなければ、依頼された作問または採点の前に既定8問を一つ作成する。既にあれば追加しない。
4. 利用者が学習記録を変更しないよう明示した場合は、自動作成を行わない。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py quick-review-status \
  --root . --date YYYY-MM-DD
```

quick-review Sessionを作る場合は、[問題作成ワークフロー.md](問題作成ワークフロー.md)の選定・作成・検証手順を使う。作成完了後、元の依頼へ戻る。
