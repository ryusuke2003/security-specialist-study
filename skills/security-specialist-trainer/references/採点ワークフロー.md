# 採点ワークフロー

## 採点前チェック

1. 問題文を読む前に `python3 skills/security-specialist-trainer/scripts/study_helper.py grading-candidates --root .` を実行する。出力全件を作業対象とし、見た目の `Status`、Git差分、コミット履歴で絞らない。
2. 次の全保存先を調べる: 現行の `学習記録/理解・応用問題/`、`学習記録/暗記語句問題/`、`学習記録/10分復習/`、旧 `学習記録/standard/`、`学習記録/term-recall/`、直下の `学習記録/YYYY-MM-DD.md`。HTMLの回答プレースホルダは空欄として扱う。全問回答済みで、採点ブロックまたはProgress更新が欠けるSessionだけが候補である。利用者指定の `cancelled` は除外する。
3. 日付・Session番号の指定がなければ、候補全件を日付、Session番号の昇順に採点する。未回答Sessionは未回答のQ番号を伝えるが、他の採点を妨げない。重複するPrimary Termの進捗を正しく更新するため、前のSessionの記録を終えてから次を処理する。
4. `わかりません` は回答済みの `0 / 100` とする。10分復習は一つだけチェックされたA/B/Cを `100 / 100` または `0 / 100` とし、未選択・複数選択は未回答とする。quick-reviewは `record --mode quick-review` で採点完了だけを記録し、理解度進捗を更新しない。

## 採点・記録

各問題のメタデータ・回答を読み、意味内容で採点する。通常問題は問題文が求めた観点だけを100点へ正規化し、未要求の補足知識を理由に減点しない。暗記語句問題は近接概念と区別する最小限の定義要素だけを評価する。各回答には既存ブロックを置換して、点数、良かった点、足りない点・誤解、短い模範的な説明、次回確認する観点を記す。SessionのStatusはこの時点で `grading` にする。

全問に有効な点数が付いた後、次を実行する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py record \
  --root . --date YYYY-MM-DD --session N --mode standard|term-recall
```

現行日本語ディレクトリでは、`Mode`、問題数、Q1からの連番、ディレクトリとModeの組合せを満たす必要がある。暗記語句ではPrimary Term一つ、Level 1、Track A/Bの配分も検証される。記録処理が、各理解度、学習履歴、Session Summary、活動ログ、モチベーション、未解答・未復習一覧を更新し、最後にStatusを `graded` にする。

記録済みより古いSessionが原因で失敗したときは、対象を `grading` のままにして次で進捗を時系列再構築してから再試行する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py rebuild --root .
```

それ以外の記録失敗では停止し、`graded` を手作業で設定しない。記録後はSessionと進捗3ファイルを読み直し、全問の点数、平均、重複のない語句・履歴行、次回復習日を確認する。

## 復習ノート作成

採点で新たな学びが残る場合にだけ実施する。

- 複数の主体・順序・分岐・信頼やデータの移動を扱うときだけ、`復習用/流れ図/` を全件確認して既存図を再利用する。新規図は `復習用/流れ図/<topic>.md` に置き、Mermaidで主体・受け手・対象を明示する。単純な定義には図を作らない。
- 再利用可能な説明は、`復習用/学んだこと/README.md` と最も近い `復習用/学んだこと/<分野>.md` を確認してから、当日の `## YYYY-MM-DD` の下へ重複なく追記する。新規分野を作るならREADMEにも追加する。
- 通常・暗記語句の `Score < 100` と、誤答した10分復習を翌学習日の `復習用/明日復習するべきところ/YYYY-MM-DD.md` に集約する。各項目は点数、出典、復習の要点、関連する新語を含め、点数・日付・Session・Q番号の順で並べる。出典は元Qへの正確な相対リンクとし、関連する新語は原則Importance 4以上のカタログ語句から選ぶ。
- 再処理では同じSession/Qの項目を更新し、他のSessionの項目は消さない。図を作った場合はMermaid構文も確認する。
