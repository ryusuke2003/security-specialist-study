# 問題作成ワークフロー

## 作成前の共通確認

1. `python3 skills/security-specialist-trainer/scripts/study_helper.py study-date --root .` でJSTの学習日を取得する。午前5時より前は前日であり、既存ファイル名から推測しない。
2. 問題作成または採点では、同日の `quick-review-status` を確認する。非取消の10分復習がなければ、依頼された作業の前に既定8問の10分復習を作成する。ただし「今日の10分復習」「復習問題作って」は既存の有無にかかわらず依頼分を作り、学習変更を避ける明示依頼時は作らない。
3. [出題選定ルール.md](出題選定ルール.md)を読んで、依頼の問題数・分野・モードに合わせて `study_helper.py briefing` を実行する。これは進捗全体、期限、直近出題、分野配分を内部で集約する読み取り専用コマンドであり、日常作業で進捗全体や直近Sessionを手で全読みにしない。未回答のPrimary Termは、明示的な再出題依頼がない限り除外する。
4. briefingの候補と注意を起点に採用候補を仮決定する。警告に出た元Sessionだけを読み、問題文の論点が重複しないことを確認する。briefingは候補と警告の集約であり、最終的な出題を自動確定しない。
5. [カタログ部分参照.md](カタログ部分参照.md) に従い、採用候補、問題に使う関連語、必要な直接前提の行だけを確認する。日常の作問で概念カタログ全体を読まない。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py briefing \
  --root . --date YYYY-MM-DD --mode MODE --count N
```

暗記語句は `--mode term-recall`、10分復習は `--mode quick-review` を指定する。

## 通常問題

- 通常問題は `学習記録/理解・応用問題/YYYY-MM-DD.md` へ書く。状況、ログ、設定、攻撃経路、運用手順から、確認点・影響・対策優先度などを判断させる。純粋な説明問題は原則1問までとする。
- 問題文の重複、答えや誘導的なヒントは避ける。
- 書式は [通常・暗記語句Session形式.md](../../../参照資料/通常・暗記語句Session形式.md) を読む。

## 暗記語句問題

- 用語暗記の依頼だけに使う。
- `学習記録/暗記語句問題/YYYY-MM-DD.md` に書き、各問のPrimary Termは正確に一つ、同Session内で重複させない。短い「用語とは何ですか？」形式で、核となる定義を一文で答えられる問いにする。
- plannerの結果を無作為な選定で置き換えない。
- 書式は [通常・暗記語句Session形式.md](../../../参照資料/通常・暗記語句Session形式.md) を読む。

## 今日の10分復習

- 依頼時または作成前確認で必要な場合、`学習記録/10分復習/YYYY-MM-DD.md` に `Mode: quick-review` で作る。
- 各問は正解一つのA/B/C三択にし、各選択肢を `- [ ] A. ...` 形式にする。回答欄や正解は置かない。選択肢は、役割・条件・主体・範囲・順序が近いもっともらしい誤答にする。
- 書式は [10分復習Session形式.md](../../../参照資料/10分復習Session形式.md) を読む。

## Session形式・検証・索引更新

共通の保存先・メタデータ・検証は [セッション形式.md](../../../参照資料/セッション形式.md) を正本とする。問題作成後は `学習記録/未解答一覧.md` と `復習用/未復習一覧.md` を更新し、問題数、Q1からの連番、メタデータ、回答欄または選択肢を確認する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py unanswered --root .
python3 skills/security-specialist-trainer/scripts/study_helper.py unreviewed --root .
```

利用者には、絶対パスのSessionリンク、問題数、指定された重点だけを簡潔に返す。
