# 問題作成ワークフロー

## 作成前の共通確認

1. `python3 skills/security-specialist-trainer/scripts/study_helper.py study-date --root .` でJSTの学習日を取得する。午前5時より前は前日であり、既存ファイル名から推測しない。
2. 問題作成または採点では、同日の `quick-review-status` を確認する。非取消の10分復習がなければ、依頼された作業の前に既定8問の10分復習を作成する。ただし「今日の10分復習」「復習問題作って」は既存の有無にかかわらず依頼分を作り、学習変更を避ける明示依頼時は作らない。
3. `進捗/` 全体と、通常・暗記語句の直近3ファイルを読む。進捗とカタログを選定根拠にし、最近のSessionは問題文重複の確認だけに使う。日常作業で過去問PDFや索引は読まない。
4. `study_helper.py plan` を依頼の問題数・分野・モードに合わせて実行する。明示された問題数は1〜30の範囲だけ受け付ける。未回答のPrimary Termは、明示的な再出題依頼がない限り除外する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py plan \
  --root . --date YYYY-MM-DD --mode MODE --count N
```

暗記語句は `--mode term-recall`、10分復習は `--mode quick-review` を指定する。

## 通常問題

- 既定は6問（弱点2、期限到来1、新規2、挑戦1）で、科目B形式を70〜85%にする。6問なら5問を短い状況付きにする。初回診断は、指定がなければWeb、ネットワーク、暗号、認証、PKI、DNS、メール、マルウェアから各1問の8問にする。
- 通常問題は `学習記録/理解・応用問題/YYYY-MM-DD.md` へ書く。状況、ログ、設定、攻撃経路、運用手順から、確認点・影響・対策優先度などを判断させる。純粋な説明問題は原則1問までとする。
- 弱点にはLevel 1〜3、実証済みの強みにはLevel 4〜6を使う。問題文の重複、答えや誘導的なヒントは避ける。

## 暗記語句問題

- 用語暗記の依頼だけに使う。指定がなければ10問、`Mode: term-recall`、Level 1、Trackは `A = floor(問題数 × 0.40)`、残りBとする。
- `学習記録/暗記語句問題/YYYY-MM-DD.md` に書き、各問のPrimary Termは正確に一つ、同Session内で重複させない。短い「用語とは何ですか？」形式で、核となる定義を一文で答えられる問いにする。
- taxonomyのTrack BはSessionでもB、AまたはA/BはAとする。plannerの結果を無作為な選定で置き換えない。

## 今日の10分復習

- 依頼時または作成前確認で必要な場合、`学習記録/10分復習/YYYY-MM-DD.md` に `Mode: quick-review` で作る。既定8問は期限超過4、当日期限2、低得点2を優先する。
- 各問は正解一つのA/B/C三択にし、各選択肢を `- [ ] A. ...` 形式にする。回答欄や正解は置かない。選択肢は、役割・条件・主体・範囲・順序が近いもっともらしい誤答にする。

## Session形式・検証・索引更新

正確な保存先、メタデータ、見出し、回答欄、選択肢、採点ブロックの形式は必ず [セッション形式.md](../../../参照資料/セッション形式.md) を正本とする。問題作成後は `学習記録/未解答一覧.md` と `復習用/未復習一覧.md` を更新し、問題数、Q1からの連番、メタデータ、回答欄を確認する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py unanswered --root .
python3 skills/security-specialist-trainer/scripts/study_helper.py unreviewed --root .
```

利用者には、絶対パスのSessionリンク、問題数、指定された重点だけを簡潔に返す。
