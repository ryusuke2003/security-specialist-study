# カタログ拡張・過去問調査

この手順は、利用者が明示的に「カタログを拡張して」「過去問を踏まえて用語を追加して」などと依頼した場合だけに使う。通常の問題作成・採点・復習では読まない。

1. `進捗/語句別理解度.md` を確認し、既存語句の未評価・弱点と追加候補の重複を把握する。
2. `参照資料/過去問分析索引.md` と、利用可能ならローカルの `過去問/` PDFを調べる。PDFがない年は、必要に応じて公式IPA資料を参照する。
3. 分析結果を `参照資料/過去問分析索引.md` に、テーマ・候補語・根拠年を簡潔に記録する。
4. 候補は、繰り返し出る語句、科目Bシナリオの読解に必要な語句、既存語句の前提となる語句を優先する。午前IIで一度でも問われ、既存語句だけでは説明しにくい語句、再利用できる標準・攻撃・運用要素、現行機構へ素直に対応付けられる旧語も検討できる。
5. 根拠がある語句だけを `参照資料/出題分類と概念カタログ.md` に追加する。既存語句の削除・改名・重複追加はしない。`Importance` と `Related` は既存の表記・基準に合わせ、カタログの出典日・件数注記と影響する利用者向け資料も更新する。

追加後に、更新済みカタログから問題選定を行う。
