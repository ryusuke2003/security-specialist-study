# 10分復習採点ワークフロー

共通開始処理と`grading-candidates`による対象特定を終えた後、`Mode: quick-review`のSessionだけをこの手順で採点する。通常・暗記語句のSessionには[採点ワークフロー.md](採点ワークフロー.md)を使う。

## 採点

1. 各問でA/B/Cのうち一つだけチェックされていることを確認する。未選択・複数選択は未回答とし、Sessionを採点しない。
2. 正答は`100 / 100`、誤答は`0 / 100`とする。
3. 正答には点数だけを記録する。

   ```markdown
   ### 採点

   Score: 100 / 100
   ```

4. 誤答にだけ、正解の理由と選んだ選択肢が不適切な理由を短く記録する。

   ```markdown
   ### 採点

   Score: 0 / 100

   #### 解説

   <正解の理由と誤答の理由>
   ```

5. 全問へ点数を付けたらSessionのStatusを`grading`にする。過去の採点済みSessionにある旧形式の採点ブロックや、正答へ付けられた解説は変更しない。

## 記録と復習

次を実行する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py record \
  --root . --date YYYY-MM-DD --session N --mode quick-review
```

`record`は採点完了、活動ログ、未解答一覧だけを更新する。3択の結果では`語句別理解度.md`、`分野別理解度.md`、`学習履歴.md`を更新しない。正答は復習対象にしない。

誤答したPrimary Termだけを、採点日の翌学習日に対応する`復習用/明日復習するべきところ/YYYY-MM-DD.md`へ追加する。見出し直下に`- [ ] 復習済み`を置き、点数、元Qへの相対リンク、復習の要点、関連する新語を記す。同じSession/Qを再処理するときは既存項目を更新する。

最後に次を実行し、今回の誤答項目がすべて掲載され、正答項目が掲載されていないことを確認する。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py unreviewed --root .
```
