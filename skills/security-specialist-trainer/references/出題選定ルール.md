# 出題選定ルール

日常の問題作成ではこのファイルを選定の正本とする。採点方法、進捗更新式、採点後の復習ノート作成は[採点・理解度・復習ルール.md](../../../参照資料/採点・理解度・復習ルール.md)と採点ワークフローを読む場合だけ必要である。

## 難易度と復習期限

- 直近のモード別理解度に応じて、0〜39はLevel 1、40〜59はLevel 2、60〜74はLevel 3、75〜87はLevel 4、88〜94はLevel 5、95〜100はLevel 6を目安にする。誤答直後は一段下げ、高得点が続けば一段上げる。
- 通常問題の弱点・期限はExplanation Score、暗記語句の弱点・期限はRecall Scoreを使う。自己モードが未評価なら未学習として扱い、もう一方の弱点も候補優先度へ反映する。
- 復習期限は、現在Scoreが0〜39なら1日、40〜59なら2日、60〜74なら5日、75〜89なら12日、90〜100なら30日を基本とする。期限超過、低得点、未学習、重要度、弱い関連語、最近少ない分野を優先し、直近の同語句は抑制する。未回答の出題済みPrimary Termは明示的な再出題依頼がない限り除外する。

## 配分

- 通常Sessionは既定6問を、弱点2、期限到来1、新規2、挑戦1にする。7問以上では追加分をすべて新規にする。利用者が分野や比率を指定した場合はそちらを優先する。
- 通常問題は科目B形式を70〜85%にし、6問なら5問を状況付きにする。初回診断は、指定がなければWeb、ネットワーク、暗号、認証、PKI、DNS、メール、マルウェアを各1問の8問にする。
- 暗記語句は指定がなければ10問、Level 1、`Mode: term-recall` とする。Trackは `A = floor(問題数 × 0.40)`、残りをBにし、taxonomyのBはB、A/A-BはAに割り当てる。
- 10分復習は既定8問で、期限超過4、当日期限2、低得点2を優先する。A/B/Cの三択に`D. わかりません`を加え、選択結果は理解度進捗を更新しない。

## Plannerの扱い

`study_helper.py briefing` は `plan` と同じ候補選定を使い、進捗・忘却・重要度・関連・最近の出題に加えて、採用候補、分野配分、直近3 Sessionの既出元を集約する。前提不足、問題文重複、利用者の明示的な重点と矛盾しないかを確認してから採用し、無作為な候補へ置き換えない。候補の正式名称・関連語・直接前提は[カタログ部分参照.md](カタログ部分参照.md)に従って確認し、通常の作問で概念カタログ全体を読まない。briefingは出題の自動確定ではない。
