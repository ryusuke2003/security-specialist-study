# 情報処理安全確保支援士・適応学習ノート

情報処理安全確保支援士試験（セキスペ）の科目A・科目Bを、Markdownで記録しながら反復学習するためのリポジトリです。

短い暗記語句問題で「思い出す力」を、理解・応用問題で原理・条件・対策・シナリオを説明する力を育てます。

## 使い始める

1. このリポジトリを作業場所として開く
2. チャットで「問題作って」または「暗記語句問題作って」と依頼する
3. 理解・応用問題・暗記語句問題は各 `### 回答` の下に回答を書き、10分復習は選択肢を一つチェックする
4. チャットで「採点して」と依頼する

未解答の問題は、[未解答一覧](学習記録/未解答一覧.md)で確認できます。各行のリンクから該当するSessionファイルを開けます。

採点したSessionは、[行ったこと](学習記録/行ったこと.md)で日付・問題形式ごとに確認できます。採点時のJST学習日をSessionへ記録して追記するログなので、コミット日時には依存しません。

まだチェックしていない復習項目は、[未復習一覧](復習用/未復習一覧.md)で確認できます。日付別の復習ノートを正本とする自動生成一覧で、問題作成・採点の後に更新されます。手でチェックを変えた後は「未復習一覧を更新して」と依頼してください。

## 学習を始めるとき

1. [前回行ったこと](学習記録/行ったこと.md)を確認する
   - まだ読めていない解説や復習ポイントがあれば確認する。
2. [未復習一覧](復習用/未復習一覧.md)を確認する
3. [未解答一覧](学習記録/未解答一覧.md)を確認しながら取り組む
   1. [10分復習](学習記録/10分復習/)を行う
   2. 次の問題に取り組む
      - [暗記語句問題](学習記録/暗記語句問題/)
      - または [理解・応用問題](学習記録/理解・応用問題/)

## 問題の種類

| 種類 | 通常の問題数 | ねらい |
|---|---:|---|
| 理解・応用問題 | 6問 | 原理、成立条件、対策、ログや設定を使う判断を説明する |
| 暗記語句問題 | 10問 | 用語の核心を一文で思い出す |
| 今日の10分復習 | 8問 | 3択で、期限超過・今日の復習・低得点を短時間で確認する |

学習日はJST午前5時に切り替わります。00:00〜04:59は前日扱いとなり、10分復習と翌日復習のファイル日付もこの基準に従います。

理解・応用問題は、弱点2問・復習1問・新規2問・発展1問が基本です。7問以上を指定した場合、追加分はすべて新規問題になります。

通常6問のうち5問は、ログ・設定・構成・運用手順・攻撃経路から確認点、原因・影響、対策の優先順位を判断する科目B形式です。問題数、分野、科目B寄り、弱点中心などは自然文で指定できます。

暗記語句問題は、既定10問で用語の核心を一文で説明するLevel 1形式です。問題数は1〜30問で指定できます。採点では、その用語を近い概念と区別するために必要な要素がすべて含まれることを満点条件とし、同義表現は認めます。空欄でなくても必須要素が欠ければ部分点となりますが、目的・具体例・対策など定義に不要な補足の不足では減点しません。

「今日の10分復習」は、1問約75秒を目安にA/B/Cの3択で解きます。選択肢のチェックボックスを一つだけ選んで回答します。誤答も、近い仕組み・役割の違い・条件漏れを問う選択肢にし、正解だけが設問の条件をすべて満たすようにします。正解は当て推量の影響があるため理解度スコアを上げず、不正解は次の学習日用チェックリストにも記載して復習します。

このリポジトリでは、問題作成または採点を始めるときに、その日の10分復習が未作成なら先に自動で1Session作成します。挨拶や資料確認では作成しません。「今日の10分復習」または「復習問題作って」と明示した場合は、当日分があっても依頼したSessionを作成します。

## 回答と採点

思い出せないときは、理解・応用問題・暗記語句問題のどちらでも空欄にせず、`わかりません` と記入してください。未回答として止めず、0点と復習ポイントを記録します。

「採点して」は、すべて回答済みで採点・進捗更新が未完了のSessionを、`Status`表記に依存せず古い順に処理します。空欄があるSessionは飛ばし、未回答番号だけを知らせます。

## 復習と学習記録

- 学習履歴の正本は、人が読めるMarkdownである `学習記録/` と `進捗/` です。
- [分野別理解度](進捗/分野別理解度.md)には、点数だけでなく到達証拠を表示します。暗記だけの「用語想起のみ」、通常説明を解いた「応用まで確認」、Level 5以上・90点以上の通常説明を2問以上解いた「高難度で安定」を区別し、重要度4〜5で未評価の語句数も確認できます。
- [モチベーション](進捗/モチベ.md)では、全体と分野別の語彙カバレッジに加え、未評価・暗記のみ・応用のみ・両方確認の内訳を確認できます。
- 出題候補の選択と採点結果の反映には、リポジトリ内の `security-specialist-trainer` Skillを使います。
- 採点で得た補足は、分野別ノートの[学んだこと](復習用/学んだこと/README.md)へ残します。同じ分野・同日のメモは一つの日付見出しにまとめます。
- 複数の手順を追うテーマは[流れ図](復習用/流れ図/)に保存します。
- 採点した次の学習日の復習項目は、[明日復習するべきところ](復習用/明日復習するべきところ/README.md)の日付別チェックリストへまとめます。

次の学習日用チェックリストには、理解・応用問題と暗記語句問題の100点以外の回答に加え、10分復習の不正解を載せます。元の問題を開かなくても復習できる短い解説と関連する新語を付け、問題形式を分けずに点数の低い順で並べます。同点は出典の日付・Session・問題番号順です。

各項目は見出しの直下にタスクリスト形式のチェック欄を置き、出典・復習の要点・補足情報を分けて表示します。出典は元のSessionの該当問題へ直接移動できるリンクです。復習できた項目は `[ ]` を `[x]` に変更できます。

採点日に作成または内容を補った流れ図が問題に対応する場合は、翌日用チェックリストの項目から図へ移動できます。

## 出題の根拠と過去問

暗記語句カタログは、IPAの試験シラバスと過去問を基準に18分野・151語まで広げています。頻出性、科目Bでの説明必要性、前提度が高い重要度5の語句は、未学習の同程度の候補より優先します。一方で、弱点や復習期限の語句も取りこぼさない設計です。

日々の出題は [出題分類と概念カタログ](参照資料/出題分類と概念カタログ.md)と`進捗/`を根拠に行います。151語を暗記語句問題で1周した後だけ過去問PDFを分析し、80〜120語を追加して約250語へ広げます。約250語を1周した後は、不足が見えた場合だけ20〜40語ずつ追加します。

暗記語句と理解・応用は、得点だけでなく復習期限も別々に管理します。暗記で正答しても、説明・応用の復習期限は後ろへ動きません。

Session Summaryの「次回復習」は固定の学習予定日ではなく、次に学習を始めたときに優先する目安として表示します。進捗表の日付は、忘却度と出題優先度を計算するために使います。

回答欄が空の問題に割り当て済みの語句は、次の通常出題では重複させません。未回答問題をもう一度復習したい場合だけ、その旨をチャットで指定できます。

採点時はGitの差分ではなく、通常・暗記語句問題はSession本文の各回答欄を、10分復習はチェック済み選択肢を直接確認します。回答をコミット済みでも、未採点なら採点対象です。

IPAの問題冊子・解答例・採点講評は、ローカルの`過去問/`へ保存できます。このディレクトリはGit管理外です。PDFの分析結果は[過去問分析索引](参照資料/過去問分析索引.md)へ記録し、カタログ拡張時に参照します。チャットで「過去問を参照して」と明示された場合は、索引だけでなくPDFそのものも確認します。
