# セッション共通形式

全Sessionに共通する保存先、識別子、メタデータ、検証ルールの正本である。問題形式ごとの詳細は、必要なものだけを読む。

- 理解・応用問題または暗記語句問題: [通常・暗記語句Session形式](通常・暗記語句Session形式.md)
- 今日の10分復習: [10分復習Session形式](10分復習Session形式.md)
- 採点、進捗更新、状態判定: [採点ワークフロー](../skills/security-specialist-trainer/references/採点ワークフロー.md)

## 保存先とSession番号

理解・応用問題は `学習記録/理解・応用問題/YYYY-MM-DD.md`、暗記語句問題は `学習記録/暗記語句問題/YYYY-MM-DD.md`、今日の10分復習は `学習記録/10分復習/YYYY-MM-DD.md` に保存する。ファイル名の日付はJST午前5時に切り替わる学習日とし、00:00〜04:59は前日の日付を使う。

同じ日付について現行3ディレクトリと旧パスにあるSession番号を確認し、全体の最大番号へ1を足す。これにより `Applied Sessions` とhistoryで使う `YYYY-MM-DD#Session番号` を一意に保つ。

旧 `学習記録/YYYY-MM-DD.md`、`学習記録/standard/YYYY-MM-DD.md`、`学習記録/term-recall/YYYY-MM-DD.md` は読み込み・採点・進捗再構築のため引き続き受け付ける。ただし、新しいSessionは必ず日本語名のモード別ディレクトリへ書く。

## 共通メタデータと問題ブロック

全Sessionの先頭には、次の形でSessionとQを置く。モード別の追加メタデータは各詳細形式に従う。

```markdown
# YYYY-MM-DD セキスペ学習

## Session N

- Created: YYYY-MM-DD
- Status: awaiting_answers
- Mode: <mode>
- Question Count: N

### Q1

- Domain: <分野>
- Primary Terms:
  - `<主要語句>`
- Related Terms:
  - `<関連語句>`
- Level: <1-5>
- Track: <A|B>

### 問題

<問題文>
```

問題文は、メタデータの直後に置く `### 問題` 見出しの下へ通常のMarkdownとして書く。Domain、Primary Terms、Related Terms、Level、Trackは適応処理に必要なので可視メタデータとして残す。Primary TermsとRelated Termsは、語句名に `/` を含められるよう、**1語句1行のコード表記リスト**にする。区切り文字で1行へ連結しない。

現行の日本語名ディレクトリに保存するSessionは `Mode` を1行だけ必須とする。`学習記録/理解・応用問題/` は `diagnosis` または `adaptive`、`学習記録/暗記語句問題/` は `term-recall`、`学習記録/10分復習/` は `quick-review` だけを許可し、ディレクトリとModeの不一致は拒否する。Modeなしを通常問題として扱う後方互換は、旧直下と旧英語ディレクトリのSessionにだけ適用する。

`Question Count` は全Sessionで必須とし、1〜30の整数を1行だけ記載する。値は実際のQ見出し数と一致させ、Q見出しは `Q1` から重複・欠番なしの連番にする。`### Q` で始まる見出しはこの形式に完全一致させ、`QX`、`Q 2`、`Q01` のような数字以外・空白入り・先頭ゼロを許可しない。

Primary Termsには、その問題で独立に採点する中心概念だけを書く。比較問題で両方を十分に問う場合は複数でもよいが、同じSession内で同じPrimary Termを2問へ割り当てない。補助的に触れるだけの概念はRelated Termsへ分ける。カタログ掲載語句は `出題分類と概念カタログ.md` の綴りと完全一致させる。問題文には曖昧な「説明せよ」だけでなく、評価する観点を列挙する。

## 作成後の共通確認

作成後は問題数、Q1からの連番、共通メタデータ、保存先を確認し、次を実行して一覧を更新する。通常・暗記語句では標準のHTMLコメントだけが残る回答欄を、10分復習では未チェックまたは複数チェックの選択肢を未解答として扱う。`わかりません`などの記入済み回答は表示しない。

```bash
python3 skills/security-specialist-trainer/scripts/study_helper.py unanswered --root .
python3 skills/security-specialist-trainer/scripts/study_helper.py unreviewed --root .
```
