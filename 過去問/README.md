# IPA SC過去問アーカイブ

このディレクトリには、IPAが公開する2010〜2025年度の情報処理安全確保支援士試験（2010〜2016年度は情報セキュリティスペシャリスト試験）の問題冊子、解答例、採点講評を、原文のPDFのまま保存しています。

- 出典: [IPA 過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html)
- 利用上の注意: IPAは著作権を放棄していません。教育目的など試験制度の意義に反しない利用を前提とし、問題を改変していません。
- ファイル名に年度・期（`a` は秋期、`h` は春期）・試験区分・時間区分を含めています。例: `2024r06a_sc_pm_qs.pdf` は「令和6年度秋期・情報処理安全確保支援士試験・午後・問題冊子」です。

この時点で保存済みのPDFとこのREADMEは意図的にGit管理します。一方、`.gitignore`の`/過去問/`規則により、今後このディレクトリへ追加する未追跡ファイルは自動的にGit管理外になります。
